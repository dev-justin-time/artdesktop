What the shell does today

Claims here are limited to what the repository actually ships.

tab

Ten tabs, one window

Each tab mounts the official upstream web build inside the shell. The app keeps its own menus, tools, canvas and dialogs.

verified

Pinned and verified assets

Every build is pinned by tag and SHA-256 in ui/web-apps.json, downloaded at build time, checked, and bundled into the installer.

content_paste_go

Shared clipboard, wired

The shell's Rust clipboard is connected to the UI: VectorCraft can export a sample SVG and PhotoCraft can rasterize the SVG that is in the clipboard.

shield

Sandboxed frames and a CSP

App frames run under a sandbox policy with no referrer, and the webview ships a content security policy instead of no policy at all.

school

Offline Suite Expert

A deterministic retrieval assistant answers questions from the catalogue and the bundled app guides, citing its sources. No API key, no network.

smart_toy

Agent access

Module activations and clipboard updates are logged for agents, and an aggregated MCP server exposes the same catalogue and guides over stdio.
