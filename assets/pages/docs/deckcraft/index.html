DeckCraft

Slide decks and presentations, designed in Rust.

DeckCraft is an open-source presentation designer for building slide decks and slide shows, with CLI and MCP integration for scripted and agent-driven decks.

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with deckcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

Can DeckCraft build decks from the command line?
Yes. The upstream DeckCraft CLI includes an MCP server mode for headless and agent-driven deck work, and can connect to a running app.
Does DeckCraft present full-screen slide shows?
Yes. DeckCraft is a presentation and slide designer with a presentation mode, not only a static document exporter.
