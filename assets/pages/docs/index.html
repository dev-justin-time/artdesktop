How the suite fits together

01

One window, ten apps

The shell mounts the official browser build of each app as a tab, with a shared window and no separate installs.

02

Pinned and verified

Every build is pinned to a release tag, downloaded at build time, checked against a SHA-256 hash and bundled for offline use.

03

Free and open source

The shell is Apache-2.0. The ten apps are open-source Storytold projects, each with its own upstream repository.

Agent discovery

Machines can read the same catalogue the docs are built from.

A2A

A2A Agent Card

A discovery document lists every app as a skill with tags and example prompts. It is published for discovery only; the suite does not accept remote A2A tasks.

Open the Agent Card

MCP

Model Context Protocol

One aggregated stdio server exposes list_apps, search_apps, get_app_guide, recommend_app and get_agent_notifications.

LOG

Local notifications

The shell appends module and clipboard events to a local JSONL log, so an agent can follow what the user is doing without a remote service.

Suite FAQ

What is ArtCraft Studio?
ArtCraft Studio is a Rust and Tauri desktop shell that runs the official browser builds of ten Storytold creative apps in one window: PhotoCraft, VectorCraft, FilmCraft, WordCraft, DeckCraft, DesignCraft, EffectCraft, LightCraft, GridCraft and PdfCraft.
Is ArtCraft Studio free and open source?
Yes. The shell is released under the Apache-2.0 licence, and the ten upstream apps are open-source projects maintained by Storytold.
Does ArtCraft Studio work offline?
Yes. Each app build is downloaded at build time, checksum-verified, and bundled into the installer, so the suite does not need network access at runtime.
Which operating systems does ArtCraft Studio support?
Windows installers (NSIS and MSI) are built today. The Tauri codebase targets macOS and Linux as well, but those installers are not part of the current release.
How do AI agents connect to the suite?
The repository publishes an A2A Agent Card for discovery, an aggregated Model Context Protocol server exposing app guides and suite tools, and a local JSONL notification log that agents can read.
