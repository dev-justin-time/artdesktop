PDFCraft

Read, organize and edit PDF documents.

PDFCraft is an open-source PDF workbench for reading, searching, organizing, merging, splitting and annotating documents, including protected files.

Open in the suite Release notes Agent access

Features, one by one

What PDFCraft does in pdf tools, documented feature by feature.

01

Reading

Open and read PDF documents in a native viewer.

02

Search, select and copy

Find text in a document and select or copy it as text.

03

Document navigation

Move through long documents with page and outline navigation.

04

Page organization

Reorder, rotate and organize pages like cards on a table.

05

Merge and split

Combine documents or split them without re-encoding everything.

06

Protected documents

Open protected PDFs while respecting their permissions.

07

Comments and forms

Work with comments, forms, layers and attachments.

08

Keyboard-first tools

Reach common PDF tools through keyboard shortcuts.

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with pdfcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

Can PDFCraft merge and split PDFs?
Yes. PDFCraft can combine and split documents and reorganize pages without re-encoding the whole file.
Does PDFCraft open protected PDFs?
PDFCraft can open protected documents while respecting their permissions, rather than bypassing them.
