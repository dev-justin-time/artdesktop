WordCraft

Writing, typography and document design.

WordCraft is an open-source word processor for writing, page layout and document design, with command-line and MCP access for automated and agent-driven work.

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with wordcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

What makes WordCraft different from a basic text editor?
WordCraft combines writing with page layout, typography and document design, so long-form documents can be composed and styled in the same place.
Can WordCraft be automated?
Yes. The upstream project ships a command-line interface and an MCP server, and the suite's MCP server exposes WordCraft guidance to agents.
