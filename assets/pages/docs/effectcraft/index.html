EffectCraft

Motion graphics, VFX and 3D in one studio.

EffectCraft is an open-source motion graphics and visual effects studio with animation, effects, 3D and export tools, plus agent and MCP integration.

Open in the suite Release notes Agent access

Features, one by one

What EffectCraft does in motion graphics, documented feature by feature.

01

Animation

Animate layers, properties and keyframes on a timeline.

02

Effects

Apply visual effects and compositing operations to footage and generated layers.

03

3D workspace

Work with 3D layers and compositing alongside 2D motion graphics.

04

Export

Render the finished composition to a deliverable file.

05

Agent and MCP access

Expose the scene tree, keyframes and rendered frames to agent clients.

Where it fits

EffectCraft runs as one of ten tabs in ArtCraft Studio. Work stays on the same machine and the same window.

  • FilmCraft — Video editing

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with effectcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

Does EffectCraft do 3D?
Yes. EffectCraft includes a 3D workspace alongside animation, effects and export.
Can agents automate EffectCraft?
Yes. The upstream project ships an MCP server that exposes its scene tree, keyframes and rendered frames to agent clients.
