DesignCraft

Desktop publishing and multi-page layout.

DesignCraft is an open-source desktop publishing studio for multi-page layout, typography and print-oriented page design, built in pure Rust.

Open in the suite Release notes Agent access

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with designcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

Is DesignCraft for print or screen?
DesignCraft targets page layout and publishing, including print-oriented documents such as magazines, with typography, frames and multi-page spreads.
Does DesignCraft include a sample project?
Yes. The upstream repository ships a sample magazine that demonstrates the layout and publishing workflow.
