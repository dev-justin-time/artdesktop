PhotoCraft

Layered raster editing with real PSD files.

PhotoCraft is an open-source image editor with layers, masks, adjustment layers, layer styles, type, vectors and brushes, and it opens and saves real PSD files.

Open in the suite Release notes Agent access

Features, one by one

What PhotoCraft does in image editing, documented feature by feature.

01

Layers and masks

Stack raster layers, paint on masks and isolate adjustments without flattening the document.

02

Adjustment layers

Apply tonal and color corrections as editable, non-destructive layers.

03

Layer styles

Add editable shadows, glows and strokes that stay attached to their layer.

04

Type and vector shapes

Set editable text and draw vector shapes inside a raster document.

05

Brushes

Paint with configurable brushes directly on the canvas.

06

PSD interoperability

Open and save PSD files with layers, masks, layer styles and editable type.

07

Agent and CLI access

Automate the upstream desktop build through its command-line and MCP interfaces.

FAQ

Does PhotoCraft open PSD files?
Yes. PhotoCraft reads and writes real PSD files, including layers, masks, layer styles and editable type.
Is PhotoCraft a Photoshop replacement?
It is an open-source, clean-room reimplementation of Photoshop's editing model rather than a byte-for-byte clone, so some advanced PSD features may still differ.
