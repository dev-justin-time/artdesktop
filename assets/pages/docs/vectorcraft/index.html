VectorCraft

Precision vector illustration, built in Rust.

VectorCraft is an open-source vector art application for Bezier illustration, shape building and clean, scalable artwork, with agent and command-line access.

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with vectorcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

What is VectorCraft used for?
VectorCraft is for vector illustration: drawing and editing Bezier paths, building shapes, and producing artwork that scales cleanly for logos, icons and print.
Can AI agents drive VectorCraft?
Yes. The upstream project documents use from Claude Code and other agents, and the suite also exposes VectorCraft guidance through its MCP server.
