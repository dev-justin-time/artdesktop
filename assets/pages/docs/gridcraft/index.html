GridCraft

High-performance spreadsheets and data.

GridCraft is an open-source spreadsheet application for data, formulas and high-performance grids, with a CLI, control channel and MCP server for agents.

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with gridcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

Can agents read and edit GridCraft sheets?
Yes. GridCraft ships a CLI, a control channel for driving the running app, and an MCP server for headless agent access.
Is GridCraft built for large data sets?
GridCraft is designed as a high-performance spreadsheet with a native Rust engine and fast grid rendering.
