FilmCraft

Non-linear video editing, color, audio and titles.

FilmCraft is an open-source non-linear video editor with multi-track editing, color grading, effects, motion, audio tools, titles, captions and broad codec support.

Open in the suite Release notes Agent access

Features, one by one

What FilmCraft does in video editing, documented feature by feature.

01

Multi-track timeline

Arrange clips across tracks and trim edits with frame-accurate control.

02

Color grading

Grade footage in a dedicated color workspace alongside the edit.

03

Effects and motion

Add visual effects and animate transforms, scale and position.

04

Audio tools

Mix and shape audio on the same timeline as the picture.

05

Titles and captions

Create on-screen titles and timed captions for the finished cut.

06

Formats and export

Work with common codecs and control the export of the final master.

07

Interchange

Move projects and media between FilmCraft and other production tools.

08

Agent access

Automate editing tasks through the upstream CLI and MCP server.

Agent access

Give an agent this guide

The suite's Model Context Protocol server serves every app guide through get_app_guide. Run node scripts/mcp-server.mjs from the repository and call it with filmcraft. The upstream desktop build may also ship its own CLI and MCP server; check its release notes for those interfaces.

FAQ

Is FilmCraft a full non-linear editor?
Yes. FilmCraft provides a multi-track timeline, trimming, color, effects, motion, audio, titles and captions, and export controls in one editor.
Does FilmCraft support color grading?
Yes. Color is a first-class workspace in FilmCraft alongside editing, effects, audio and titles.
