Ten creative modules in one Rust + Tauri shell. Two working pipelines, eight interactive mockups, fully open source.

Proof of concept · Open source · Apache-2.0

One workspace.
Ten creative modules.

ArtCraft Studio is a Rust + Tauri 2.0 desktop shell that registers ten creative modules behind a shared CraftModule trait. It is deliberately a proof of concept: all ten modules embed interactive pages, eight keep their Rust actions as stubs, and PhotoCraft and VectorCraft connect their page buttons to working Rust pipelines.

One process, one clipboard, one module boundary. The README and audit spell out exactly what works and what is still stubbed — no inflated latency or GPU claims.

Quick start

$ git clone https://github.com/dev-justin-time/artdesktop.git

$ cd artdesktop

$ cargo build --workspace

$ npm --prefix crates/craft-studio-shell/ui ci

Requires Rust stable, Node.js 20+, and the Tauri 2 CLI for the desktop window.

What this is — and what it isn't

It is a working module shell, a shared clipboard and two real pipelines. It is not a finished 1.0 suite: installer bundling, most module actions and native file workflows are still ahead. The audit tracks the gap.

Built in the open. If the module boundary is useful to you, star the repo, read the audit, or open an issue with the module you want to see next.
